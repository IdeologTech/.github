# Contributing to IdeologTech

Thank you for your interest in contributing to our repositories!

## How to Contribute

1. **Fork the repository** to your personal account.
2. **Create a branch** for your work (`git checkout -b feature/amazing-feature`).
3. **Commit your changes** following standard commit conventions (`git commit -m "feat: add amazing feature"`).
4. **Push to your branch** (`git push origin feature/amazing-feature`).
5. **Open a Pull Request** describing your changes and link any related issues.

## Code Standards
- Keep code clean, readable, and free of unnecessary bloat.
- Include comments only when explaining complex non-obvious logic.
- Ensure all automated checks (linting/build) pass before requesting review.
