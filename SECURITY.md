# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within any repository under **IdeologTech**, please send an email to:

📧 **ideologtech@gmail.com**

Please provide:
- A detailed description of the issue
- Steps or code to reproduce the behavior
- Potential impact and recommended mitigation

We aim to acknowledge receipt of security reports within 48 hours and provide updates until resolution.
